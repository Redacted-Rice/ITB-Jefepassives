# Jefepassives

A community collection of passive weapons made for our YouTuber Jefepato!

Contributors
* Generic
* TheBoardCousin
* Das Keifer (Redacted Rice)
* Truelch
* Tatu

## Install

Place the `Jefepassives` folder in `Into the Breach/mods/`. When you open the folder you should see the `scripts` directory directly inside it.

## Dependencies

- ModLoader 2.9.5+
- ModLoaderExt 1.24+

## Passives

* RST Decoy - At mission start, sets up a decoy structure on a random, open tile.
